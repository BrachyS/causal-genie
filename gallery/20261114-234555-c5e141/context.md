**Demo with synthetic data: a product A/B test.** A team launched a new onboarding flow for an app and randomly assigned new sign-ups 50/50 to the new or old flow. They want to know whether the new flow raised **7-day activation**, meaning the user did a key action (such as creating a project) within a week of signing up. The export, `d3_onboarding_ab.csv`, has all 6,000 users who were randomly assigned (sign-up date, platform, flow, activated in 7 days). It was generated for this demo, with a true effect of +5 percentage points built in, so the Genie's estimate can be checked against the truth. Compare it with the **completers only** run of the same question.
