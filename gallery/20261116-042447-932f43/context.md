**Demo with synthetic data: a product A/B test.** A team launched a new onboarding flow for an app and randomly assigned new sign-ups 50/50 to the new or old flow. They want to know whether the new flow raised **7-day activation**, meaning the user did a key action (such as creating a project) within a week of signing up. The analyst's export, `d4_onboarding_completers.csv` (3,776 users: platform, sign-up date, flow, activated in 7 days, finished onboarding), was generated for this demo, so it describes no real company. It tests whether the Genie checks how the data was collected before it estimates anything. Compare it with the **full A/B data** run of the same question.
